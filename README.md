### 如何使用

**iOS / macOS**：双击 `.ics` 文件，系统日历会自动弹出导入提示，iCloud 可跨设备同步。

**Windows（Outlook）**：Outlook → 文件 → 打开和导出 → 导入/导出 → 导入 iCalendar (.ics) 文件。

**Android**：将文件传到手机 → 文件管理器打开 → 选择系统日历或 Google 日历导入。

**持久订阅（推荐）**：将 `.ics` 上传到公开服务器（iCloud / GitHub Pages / WebDAV），复制链接后在设备日历中添加订阅，后续更新自动同步。

### How to Subscribe

**iOS / macOS**  
Double-click the `.ics` file → Calendar.app will prompt to add events. iCloud syncs across all Apple devices automatically.

**Windows (Outlook)**  
Outlook → File → Open & Export → Import/Export → Import an iCalendar (.ics) file.

**Android**  
Transfer the file to your phone → open with a file manager → choose Google Calendar or your preferred calendar app.

**Persistent subscription (recommended)**  
Upload the `.ics` to a public web server (iCloud, GitHub Pages, WebDAV), then add the URL as a calendar subscription on your device. Updates will sync automatically.
